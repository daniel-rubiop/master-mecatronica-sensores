# Estación de inspección de estuches de latas de conserva

Simulador 3D de una estación que, con sensores, comprueba en línea que cada estuche lleva su lata, que la lata es del tamaño correcto y tiene tapa, que las solapas están pegadas y que el estuche corresponde al cliente y al formato de la orden.

**Simulador:** https://daniel-rubiop.github.io/master-mecatronica-sensores/estuches-latas/

Se abre en cualquier navegador, sin instalar nada.
